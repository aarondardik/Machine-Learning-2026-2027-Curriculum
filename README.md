# Machine-Learning-2026-2027-Curriculum
This is a repository that will contain notes, code skeletons, solutions, worked problems etc. that will form the foundation of the machine learning course I will teach in 2026-2027.

Note that I have taught a machine learning course in 2024-2025 and 2025-2026. Each year represented students with different skill levels, interests, strengths and weaknesses. While some old material may be uploaded to a folder for reference, the aim of this repository is to contain the resources students need to excel in next years course.
